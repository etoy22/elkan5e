Elkan 5e content for Foundry VTT's dnd5e system: most of [Elkan 5e](https://elkan5e.com), ready to drop into your game worlds, with automation built in.

## Installation

Search for **Elkan 5e** in Foundry's **Install Module** window.

You can also install it by hand:

- **Manifest URL**: paste this into the *Manifest URL* field at the bottom of the **Install Module** window:

  ```
  https://github.com/etoy22/elkan5e/releases/latest/download/module.json
  ```

- **Direct download**: download [module.zip](https://github.com/etoy22/elkan5e/releases/latest/download/module.zip) and extract it into your Foundry `Data/modules` folder.

## Requirements

| | Version |
| --- | --- |
| Foundry VTT | v14 |
| dnd5e system | 6.x |

### Recommended Modules

Most automation works with dnd5e alone. These modules add more:

- [Midi-QOL](https://foundryvtt.com/packages/midi-qol): fuller attack, save, and reaction automation
- [Dynamic Active Effects (DAE)](https://foundryvtt.com/packages/dae): advanced effect handling
- [socketlib](https://foundryvtt.com/packages/socketlib): lets players' features change creatures they don't own

## Version Numbers

Each release number shows which Foundry and dnd5e versions it's built for. For example, **v14.6.0** means:

- **14**: Foundry VTT v14
- **6**: dnd5e 6.x
- **0**: the Elkan 5e release

See the [changelog](CHANGELOG.md) for what's changed in each release.
